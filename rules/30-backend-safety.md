# 백엔드 안전 규칙
- DB 스키마 변경은 마이그레이션 파일(Flyway/Liquibase/EF Migrations)로만 한다. 기존 마이그레이션은 수정하지 않는다. 롤링 배포 중 구·신 코드가 함께 동작하도록 설계한다(expand → contract).
- 트랜잭션 경계, 동시성, 멱등성, 재시도에 영향을 주는 변경은 사용자에게 명시적으로 알린다.
- 설정 파일의 시크릿 값(비밀번호, 토큰, 연결 문자열)은 출력하지 않는다. 키 이름만 언급한다.
- 운영/공유 환경(DB, 메시지 브로커, 클라우드)에 쓰기 작업을 하지 않는다. 필요하면 명령만 제안한다.
- 로컬·테스트 환경(로컬 DB, Testcontainers, docker-compose, 임시 파일)은 확인 없이 사용해도 된다.
