# Jira·Confluence 생성

Jira 이슈 또는 Confluence 페이지를 만들어 달라는 요청에 적용한다.

- 먼저 현재 연결된 Atlassian 도구에서 Jira 이슈 생성 또는 Confluence 페이지 생성 기능을 확인한다. 검색·조회 기능만으로 생성됐다고 간주하지 않는다.
- 생성 도구가 있으면 대상 프로젝트/스페이스, 이슈 유형, 제목, 설명/본문, 라벨, 담당자, 부모 페이지 등 도구의 필수 입력을 확인한다. 사용자 요청과 참조한 가이드에서 확인할 수 없는 필수 정보는 지어내지 말고 질문한다.
- 생성 전 같은 프로젝트/스페이스에 같은 제목의 항목이 있는지 확인해 중복 생성을 피한다. 기존 항목이 있으면 새 항목을 만들지 말고 사용자에게 알린다.
- 사용자가 생성 요청을 한 경우 도구로 생성하고, 반환된 이슈 키/페이지 ID로 다시 조회해 생성 결과와 링크를 확인한다. 확인된 결과만 성공으로 보고한다.
- 생성 도구가 없으면 현재 연결 상태가 조회 전용임을 알리고 생성 완료라고 말하지 않는다. 하네스 룰은 MCP 기능이나 Atlassian 권한을 추가하지 않으므로, 생성 기능이 제공되는 Atlassian 커넥터/MCP 연결이 필요하다고 설명한다. 확보한 정보로 복사 가능한 제목·본문·필드 초안을 제공한다.
